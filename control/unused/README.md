# Unused MPC Files

This directory contains MPC-related files that are not currently used in the main system.

## Purpose

Files in this directory are kept for reference or future use but are not actively integrated into the production system.

## Current Status

- All active MPC code is in the parent `control/` directory
- Files here are archived for potential future use or reference

## Notes

- These files may contain experimental implementations
- They may be useful for research or alternative approaches
- Do not import from this directory in production code
